# Code de conduite / Code of Conduct

**English summary.** Be respectful, argue with evidence, accept negative results, never encourage gambling or promise
winnings, never accuse a lottery operator of fraud on statistical grounds alone.

---

## Principes

1. **Respect.** Pas d'insultes, de harcèlement ni de propos discriminatoires. On critique les arguments, pas les personnes.
2. **Preuves d'abord.** Une affirmation sur les tirages s'appuie sur un test déclaré à l'avance, corrigé des
   comparaisons multiples et validé hors échantillon. Une p-value isolée n'est pas une preuve.
3. **Un résultat négatif est un résultat.** Annoncer « aucune structure détectée » est légitime et attendu.
4. **Pas de promesse de gain.** Ce projet ne vend pas de pronostics, de « systèmes gagnants » ni de numéros. Les
   contributions qui présentent un outil comme capable de prédire les tirages sans validation hors échantillon seront
   refusées.
5. **Pas d'accusation de fraude** fondée sur des statistiques seules. Une anomalie statistique appelle une
   investigation, pas une accusation.
6. **Jeux d'argent.** Jouer comporte un risque de perte et peut créer une dépendance. Si le jeu devient un problème,
   parle-en à un professionnel de santé.

## Application

Les mainteneurs peuvent supprimer tout commentaire ou contribution contraire à ces principes, et bloquer leurs
auteurs en cas de récidive. Pour signaler un comportement, ouvre une issue ou contacte les mainteneurs du dépôt.
